# Pratibha AI — Multi-Agent Pipeline Documentation

Autonomous AI Recruitment Platform · Next.js 15 · Google GenAI (TypeScript) · Gemini 3.1

## Agent Overview

| # | Agent | Model | Output |

## Agent Details

### Agent 1 — Orchestrator
**Model:** `gemini-3.1-pro`
**File:** `src/app/api/agents/orchestrator.ts`

- Creates pipeline session state
- Routes tasks to all downstream agents in order
- Manages parallel candidate extraction across multiple resumes
- Collects and passes outputs between agents

---

### Agent 2 — Job Intelligence
**Model:** `gemini-3.1-pro`
**File:** `src/app/api/agents/job-intelligence.ts`

- Reads raw job description text
- Extracts: required skills, preferred skills, must-have keywords, deal breakers
- Identifies: role archetype, seniority signals, leadership requirements
- Sets: priority weights (skills/technical/culture), technical depth expectation
- Output: `HiringBlueprint` JSON — used by all downstream agents

---

### Agent 3 — Candidate Extraction
**Model:** `gemini-3.1-flash-lite`
**File:** `src/app/api/agents/candidate-extraction.ts`

- Parses base64-encoded PDF/DOCX resume content
- Extracts: name, email, phone, current role, experience years, skills, education, companies
- Detects: GitHub URL, LinkedIn URL, career signals (leadership, startup, enterprise)
- Infers: candidate seniority level, career summary
- Output: `CandidateProfile` JSON — foundation for all evaluation agents
- Runs **in parallel** for multiple candidates

---

### Agent 4 — Verification / Risk
**Model:** `gemini-3.1-flash-lite`
**File:** `src/app/api/agents/verification-risk.ts`

- Detects resume inflation signs (exaggerated titles, inflated scope claims)
- Checks employment timeline consistency (overlapping dates, gaps)
- Flags suspicious or unverifiable claims
- Scores: overall risk (0–100), verification confidence (0–100), resume consistency (0–100)
- Output: `RiskReport` — risk level, flags, inflation signs, risk categories

---

### Agent 5 — Technical Validation
**Model:** `gemini-3.1-flash`
**File:** `src/app/api/agents/technical-validation.ts`

- Fetches GitHub profile via GitHub REST API
- Analyzes: repository count, language distribution, commit frequency, project quality
- Validates technical claims from resume against actual GitHub evidence
- Scores: Technical Depth Score (0–100) with confidence rating
- Output: `TechnicalValidationResult` — github analysis summary, tech depth assessment

---

### Agent 6 — Behavioral Alignment
**Model:** `gemini-3.1-flash-lite`
**File:** `src/app/api/agents/behavioral-alignment.ts`

- Evaluates observable professional behavioral signals from resume
- Analyzes: leadership signals, collaboration evidence, ownership patterns, career progression
- Assesses: work-style indicators (autonomy, collaboration, leadership levels)
- Checks: culture keyword alignment, work environment fit
- Scores: Culture Fit Score (0–100) with behavioral confidence
- Output: `BehavioralAlignmentResult` — strengths, concerns, work-style indicators
- **Never** infers personality, emotional traits, or protected characteristics

---

### Agent 7 — Evaluation Aggregator
**Model:** `gemini-3.1-flash-lite`
**File:** `src/app/api/agents/evaluation-aggregator.ts`

- Aggregates scores from Agents 4, 5, 6 using weighted formula
- Formula: `(Skills × 40%) + (Technical × 35%) + (Culture × 25%)`
- Computes: required skill coverage %, preferred skill coverage %, keyword alignment %
- Detects: scoring inconsistencies, evaluation conflicts
- Adjusts: confidence-adjusted composite score when evidence quality is low
- Output: `AggregatedScore` — composite score, rank label, strength areas, gap areas

**Score Tiers:**
- 90–100 → `strong_hire` / "Strong Hire"
- 65–89 → `consider` / "Consider"
- 0–64 → `not_recommended` / "Not Recommended"

---

### Agent 8 — Decision Agent
**Model:** `gemini-3.1-pro`
**File:** `src/app/api/agents/decision-agent.ts`

- Synthesizes all upstream evaluation outputs into an explainable recommendation
- Generates: why-hire rationale, strength highlights, gap highlights
- Assesses: risk impact on overall hiring decision
- Creates: targeted interview questions for unresolved concerns
- Scores: decision confidence (0–100) based on evidence consistency
- Flags: manual review when confidence is low or conflicts exist
- Output: `DecisionResult` — recommendation, decision rationale, interview questions
- **Final hiring authority always belongs to the human reviewer**

---

### Agent 9 — Report Generator
**Model:** `gemini-3.1-flash-lite`
**File:** `src/app/api/agents/report-generator.ts`

- Transforms all upstream evaluation outputs into recruiter-facing reports
- Generates: executive summary, dashboard card (1 sentence), recruiter email
- Surfaces: confidence levels, evidence quality, risk severity
- Recommends: manual review when confidence or evidence is weak
- Output: `ReportData` — 24 fields covering scores, summaries, email content, warnings

**Does NOT:** evaluate candidates, modify scores, or generate new hiring reasoning.

---

## Scoring Formula

```
Composite Score = (Skills Match × 40%) + (Technical Depth × 35%) + (Culture Fit × 25%)

90–100  →  Strong Hire
65–89   →  Consider
0–64    →  Not Recommended
```

---

## Structured Output (All Agents)

All agents use Gemini native structured output:

```typescript
config: {
  responseMimeType: 'application/json',
  responseSchema: SCHEMA as unknown,
}
```

No manual JSON parsing. No `extractJSON()`. Schema-safe, deterministic output across all agents.

---

## Data Flow

```
Resume PDF/DOCX (base64)
  → [3] Candidate Extraction     → CandidateProfile
  → [4] Verification / Risk      → RiskReport
  → [5] Technical Validation     → TechnicalValidationResult
  → [6] Behavioral Alignment     → BehavioralAlignmentResult
  → [7] Evaluation Aggregator    → AggregatedScore
  → [8] Decision Agent           → DecisionResult
  → [9] Report Generator         → ReportData

[2] Job Intelligence runs once per job → HiringBlueprint
[1] Orchestrator manages the full pipeline
```
