Pratibha AI — Agent Summary
============================

#  Agent Name                  Model               Purpose
-  ----------                  -----               -------
1  Orchestrator Agent          gemini-3.1-pro      Plans the pipeline — decides which agents to run and in what order
2  Job Intelligence Agent      gemini-3.1-pro      Reads the job description and pulls out required skills, deal-breakers, and what a good candidate looks like
3  Candidate Extraction Agent  gemini-3.1-flash-lite  Reads the resume and extracts name, skills, experience, education, GitHub link
4  Verification & Risk Agent   gemini-3.1-flash-lite  Checks for fake claims, inflated skills, and timeline gaps in the resume
5  Technical Validation Agent  gemini-3.1-flash    Looks at the candidate's GitHub — repos, languages, activity — and gives a technical score (0–100)
6  Behavioral Alignment Agent  gemini-3.1-flash-lite  Checks soft skills, leadership signals, and culture fit — gives a culture score (0–100)
7  Evaluation Aggregator Agent gemini-3.1-flash-lite  Combines all scores: Skills 40% + Technical 35% + Culture 25% = Final Composite Score
8  Decision Agent              gemini-3.1-pro      Explains WHY the candidate is recommended or not, and suggests 3 interview questions
9  Report Generator Agent      gemini-3.1-flash-lite  Converts all agent outputs into a clean report + email content for the recruiter
10 Human Override Layer        N/A (Next.js UI)    Hiring manager reviews the ranked list and clicks Approve / Reject / Adjust — all actions are logged in Neon for audit
